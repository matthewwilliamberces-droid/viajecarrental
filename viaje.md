Backend Development Prompt: Antigravity (VIAJE Project)Stack: TALL Stack (Tailwind CSS, Alpine.js, Laravel, Livewire)Objective:
Develop a functional backend for the VIAJE Philippine Car Rental platform. The system requires an admin panel with authentication and inventory management. It must seamlessly integrate with the existing Alpine.js frontend without breaking the current UI or emptying the user-facing vehicle grid.  1. Database Schema & SeedingCreate a Car model and migration with a schema mirroring the existing frontend data structure:  name, category, categoryName (string)dailyRate (integer)rating (decimal), reviews (integer)seats, bags (integer)transmission, fuel, eco (string)image, badge, badgeColor (string)Critical Requirement: Create a CarSeeder that populates the database with the exact 9 default vehicles currently hardcoded in the frontend (e.g., Suzuki Jimny AllGrip, Toyota HiAce Super Grandia, BYD Atto 3). This ensures the frontend retains all visible cars during the transition to dynamic data.  2. Admin AuthenticationImplement secure admin authentication handling Login and Logout functionality.Scaffold the authentication views and logic using Laravel Breeze (Livewire version) for rapid development.Secure all administrative routes and CRUD operations behind an auth middleware barrier.3. Admin CRUD DashboardDevelop a Livewire-based dashboard for administrators to manage the Car inventory.Create: A form to add new vehicles, complete with validation for all fields.Read: A manageable data table or grid displaying the current active fleet.Update: Edit functionality to instantly modify daily rates, tags, or vehicle specifications.Delete: The ability to remove retired vehicles from the database.4. Frontend IntegrationModify the main frontend view to accept dynamic Car data from the Laravel controller instead of static HTML.Inject the database records into the existing Alpine.js viajeRentalApp() component by replacing the hardcoded fleet array with a dynamic JSON payload (e.g., fleet: @json($cars))
