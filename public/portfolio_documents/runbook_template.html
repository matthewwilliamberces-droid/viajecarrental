• Dedicated NVMe I/O Performance

Unlike shared PaaS containers that throttle CPU cycles, a dedicated Linux VPS (e.g. Hetzner CX22) provides dedicated vCPU execution and NVMe disk speeds for sub-50ms TTFB.

• Isolated Private Docker Network

Database (PostgreSQL/MySQL) and Redis instances are bound strictly to internal Docker bridge sockets. Database ports (5432 / 3306) are never exposed to the public internet.

4. Automated Off-Site Disaster Recovery (Premium)

Production databases are never left vulnerable on a single physical host. In the Premium architecture, automated snapshot routines are configured to ship encrypted database dumps to S3-compatible cloud storage:

• Daily Scheduled DB Dumps

Automated database backup jobs execute every 24 hours during off-peak hours (03:00 UTC), gzipping SQL dumps directly from the container.

• Off-Site Cloudflare R2 / AWS S3 Storage

Dumps are pushed immediately to private, versioned bucket storage. In the event of catastrophic server hardware failure, full state can be restored in minutes.

5. Client Security & Handover Protocol

To eliminate developer dependency and guarantee client security, every completed deployment follows a strict 3-step security handover checklist:

Security Step Client Action Required Upon Delivery Security Benefit
1. Root Password Rotation Client logs in via SSH and executes passwd to set a private master root password. Ensures only the business owner holds master server credentials.
2. Temporary SSH Key Revocation Remove contractor SSH public keys from ~/.ssh/authorized_keys with one command. Eliminates ongoing external SSH access; locks down host access completely.
3. Coolify Master Admin Password Log into the web dashboard and rotate the administrator email and master password. Grants 100% control over applications, container logs, and deployment webhooks.
